## Baixar

A versão atual é a **0.1.0**, para Windows 10 e 11, 64 bits.

[Baixar o instalador](https://github.com/Konnak/KamoVox/releases/latest)

O arquivo se chama `KamoVox_0.1.0_x64-setup.exe`.

## O que o KamoVox faz

- Troca a voz em tempo real, com vozes prontas e ajustes de tom e timbre.
- Usa voz de inteligência artificial quando um modelo está instalado.
- Aplica efeitos por cima da voz.
- Envia a voz alterada para os outros programas pelo microfone do Windows.
- Deixa ouvir o resultado no fone antes de soltar no Discord.
- Tem push-to-talk: segure a tecla para falar e solte para silenciar.
- Toca um trecho de música direto no microfone, com atalho.
- Guarda atalhos, perfis e a opção de abrir junto com o Windows.

## Instalar

1. Baixe o instalador da [última versão](https://github.com/Konnak/KamoVox/releases/latest).
2. Abra o arquivo e conclua a instalação.
3. No KamoVox, escolha o microfone e ligue **Voz alterada nos programas**.
4. No Discord ou no jogo, selecione o mesmo microfone.

O Windows pede permissão de administrador uma vez, só para instalar o filtro de áudio no microfone.

## Atualizar

No rodapé do KamoVox, clique em **Verificar atualizações**.

Se existir uma versão mais nova, o programa baixa o instalador e abre a instalação. Não é preciso procurar o arquivo na mão.

Para publicar uma versão nova, crie uma Release neste repositório e anexe o instalador `KamoVox_*_x64-setup.exe`. O número da Release precisa ser maior do que o da versão instalada.

## Requisitos

- Windows 10 ou Windows 11, 64 bits
- Um microfone
- Conexão com a internet só para baixar atualizações e modelos de voz
